## Changelog

## Changes and Additions

- **Buffed Shrine's Fortune and added Four-Leaf Fortune**

  - **Shrine's Fortune** now increases Luck by 40% for one day.
  - Added **Four-Leaf Fortune**, which increases Luck by 7% while you keep the four-leaf clover.
  - Both bonuses can stack.

- **Updated AMC trait tooltips**
  - All 28 selectable AMC traits now have hover tooltips showing the exact stat they enhance.

## Tweaks and Rebalancing

- **Chest binders now relieve chest dysphoria**
  - Chest dysphoria now uses apparent breast size, so binders and sports bras flatten the player's chest as expected.
  - Properly worn binders can occasionally cause chest pain.
  - Torn or displaced binders no longer flatten the chest or cause pressure discomfort.

## Fixes and Improvements

- **Fixed global fatigue cap initialization**

- **Fixed Tempered Milk and Semen Volume**

  - **Tempered Milk** and **Semen Volume** are mutually exclusive again.
  - Affected saves repair automatically.
  - Liquid capacity now updates correctly when Cow, Bull, or Alpha effects change.

- **Fixed food**

  - The player can no longer eat mugs.
  - Fixed the Journal breaking in some food-related cases.

- **Fixed Whitney X-Change encounters**

  - Whitney's X-Change encounter now correctly checks whether it started in the alley or at school.
  - Removed reliance on an unused location flag that could carry the previous encounter's location into a later scene.
  - The encounter now uses the game's existing location data instead.

- **Fixed Arousal Acclimated checks**

  - **Arousal Acclimated** now works consistently anywhere high Arousal can block choices.
  - The player can leave Wren's card game while aroused.
  - Recently orgasming now correctly allows sleeping or leaving the bath at home, on the farm, and in Alex's cottage.
  - The bath's **Will yourself to get out** option now appears when the player has enough Willpower.
  - Updated the setting description to list all choices unlocked by the trait.

- **Fixed mirror menus remembering the wrong screen**

  - Closing the POCKET mirror inside a submenu, such as Makeup or Hair, no longer makes the next mirror open to that same submenu.
  - Fixed menu state carrying between other mirrors, including the park and school toilets.
  - Mirror interactions that intentionally return to the same submenu still work as before.

- **Fixed the full-body character view**
  - The full-body view now fits correctly when using **Options > Advanced > Zoom**.
  - It resizes properly at any zoom level and updates immediately when the Zoom setting changes while the view is open.
  - Closing the full-body view now stops its animation instead of leaving it running in the background.
