## Changelog
## Changes and Additions:
* Updated the **scratch action**.
  * Two-handed claw strikes now hit as hard as two hands.
  * Scratching with both hands now deals double wound damage, so a full two-clawed rake properly counts both hands.
  * To stop consensual scuffles from ending too quickly, claw and scratch damage is halved during consensual scenes.
  * Cleaned up an unused variable in the scratch combat code.
* Updated the **smoking feature**.
  * Added new feats for becoming addicted to smoking.
  * Added a smoker trait description.
  * Smoking no longer gives alcohol gain.
* Added a new **Water Dragon TF reaction for Robin**.
  * Robin can now react if the PC has a full Water Dragon manifestation, or has already unlocked it.
  * This requires Robin to have their virtual pet console.
* Added a **crop-growing plot to Avery’s mansion**.
  * If Avery has been saved, the PC can now grow crops in a glass-sheltered corner of the mansion garden.
  * The plot works like the orphanage greenhouse.
  * Avery offers it during a new conflicted “thank you” event in the garden.
  * The crop patch becomes available whether the PC accepts or declines Avery’s offer.
  * Crops can be grown there year-round thanks to the glass shelter.
* Updated the **virtual pet minigame**.
  * Added evolution.
    * A maxed-out pet can sacrifice 10 of its skills to evolve.
    * Evolutions include:
      * Embit → Blazilisk.
      * Pudduck → Pondswan.
      * Sprout → Oakguard.
      * Voltpup → Thundrover.
    * Evolution multiplies the pet’s stats.
  * Added pet and boss artwork.
  * Added stat caps.
    * Pets now cap at **5,000 HP**, **2,500 MP**, and **500 ATK / DEF / SPD**.
  * Added second pets.
    * Once a pet is maxed, the PC can adopt a second pet of a different species.
    * Both pets can be cared for.
    * Both pets can be brought into battle.
    * If one pet falls, the other tags in.
  * Added minibosses.
    * After a pet evolves, weekly attacks have a chance to become miniboss attacks.
    * Minibosses have double the player pet’s HP.
    * Minibosses only use basic attacks.
    * Defeating a miniboss drops a dungeon key.
  * Added dungeons.
    * Dungeon keys can be spent on 15-tile dungeon runs.
    * Dungeons let the player grind mobs for stats.
    * Dungeons can also contain money, fruit, and rare pills.
  * Added a monthly boss.
    * Every blood moon, a boss that mirrors the player’s pet appears.
    * The boss must be defeated within a week.
    * Failing to defeat it in time kills the pet.
  * Rebalanced enemies.
    * Enemies now use skills from the first encounter.
    * Enemies now start at 100 HP.
    * A normal mob can never be stronger than the player’s pet.
  * Robin’s booster-pack chance on arcade dates now drifts between **5% and 20%**, changing weekly.
* Updated the **chimera title picker**.
  * The mirror’s “Described as” picker can now choose unlocked hybrid titles instead of only single-species titles.
  * The game already generated blended titles automatically, such as hellhound, moon rabbit, jackalope, and fallen cat. These can now be selected manually once unlocked.
  * Added support for named chimeras, including:
    * Hellhound.
    * Dog.
    * Jackalope.
    * Moon rabbit.
  * Added support for generic blended forms, such as:
    * Fallen cat.
    * Demonic fox.
    * Angelic bear.
  * Hybrid options only appear once both halves have been unlocked.
  * Fixed a wording redundancy where named chimeras could show duplicate celestial wording.
    * For example, “a demonic hellhound” is now simply “a hellhound”.
    * This applies to both automatic titles and manual choices.
* Updated the **soup kitchen**.
  * The soup kitchen can now be entered after school on school days.
  * It can also be entered during daytime business hours on weekends and holidays.
  * Helping River at the soup kitchen now grants Grace.
  * This matches the temple’s other volunteer tasks while keeping the existing housekeeping reward.
* Added **study rewards to classes**.
  * Socialising during school lessons can now trigger new classmate moments.
  * These moments can appear in:
    * Science.
    * Maths.
    * English.
    * History.
    * Housekeeping.
  * These events give the player a chance to gain subject progress while building status.
  * Each class also has a new X-Change themed lesson event.
  * Extra attention can occur when the player is visibly X-Changed.
* Added a new feat boost: **X-Change Premium Pills**.
  * The player can now buy packs of premium pills.
  * One pack costs **10 Vrelcoins**.
  * The player can buy up to **5 packs** of Premium Pills.
* Added an **“Always show sidebar stat meters”** option.
  * X-Change normally hides sidebar stats when they are fine or maxed.
    * For example, if Control is maxed, it disappears from the side menu until it decreases.
  * This is now controlled by a toggle.
    * **On**: always show the stat meters.
    * **Off**: use the default DoLX hidden-stat behavior.
  * The default setting is **On**.
* Added **bulk-buy options**.
  * Hair gel can now be bought in bulk.
  * Hair growth formula can now be bought in bulk.
* Added a new feat: **Monogamous**.
  * This feat unlocks when all six player firsts from the stats screen are taken by the same named NPC.
  * The tracked firsts are:
    * Vaginal.
    * Penile.
    * Anal.
    * Oral.
    * Handholding.
    * Kiss.
  * The temple vow is intentionally excluded.
* Updated **Fox TF point gain**.
  * Having sex with Gwylan and Poppy now increases Fox TF gain.
  * Fox TF gain is increased further if they breastfeed the PC.
* Added **Bakunawa and Ryuuji TF** by Samz for Goose Fem.

## Rebalancing and Economy:
* Tweaked prices.
  * Cigarettes now cost **£25**, but only contain **5** cigarettes.
  * Harper’s Therapy Anti X-Change pricing has been reduced to:
    * **£10,000** for 1 day.
    * **£50,000** for 1 week.
    * **£150,000** for 1 month.
* Rebalanced the economy.
  * Added a full economy rebalance built around:
    * Player wealth.
    * Inflation.
    * Bailey rent pressure.
    * HBSC banking.
    * Income and cost adjustments.
  * Inflation now begins when the player becomes wealthy enough for the town economy to notice.
  * Inflation is based on net wealth, including:
    * Carried cash.
    * HBSC savings.
    * Fixed-term deposits.
    * Prepaid Bailey rent deposit.
    * Outstanding HBSC loan principal is subtracted from the total.
  * Prices now rise by tier:
    * **£500,000+ wealth**: +20%.
    * **£2,000,000+ wealth**: +70%.
    * **£5,000,000+ wealth**: +150%.
    * **£15,000,000+ wealth**: +300%.
    * **£100,000,000+ wealth**: +5000% Parody spiral.
  * Inflation affects player spending, not income.
  * Shop and service prices now use the same inflation calculation for both display and payment.
    * The shown price and charged price should now match.
  * The journal now reports the current economy state, including the Parody spiral tier.
* Updated Bailey’s rent pressure.
  * Bailey now reacts more strongly to visible wealth and debt.
  * Bailey’s rent uses Bailey-visible money:
    * Carried cash.
    * Liquid HBSC savings.
    * Outstanding loan principal is subtracted.
  * Locked fixed-term deposits still count for shop inflation.
  * Bailey cannot access locked deposits until they mature into savings.
  * Bailey’s rent demand now respects the Bailey rent setting, including aggressive flat demands.
  * If Bailey becomes aggressive, refusal and seduction escape options are removed where appropriate.
  * Bailey can now hunt the player in town while rent is overdue.
* Updated **HBSC banking**.
  * HBSC now supports rent-money loans.
  * Borrowed money is inflation-neutral because the loan debt cancels it out.
  * If the loan is ignored long enough, Bailey starts collecting a weekly surcharge through rent.
  * HBSC fixed-term deposits now mature automatically into savings.
  * Overflow from matured deposits goes to carried cash.
  * Locked money eventually becomes liquid again.
* Added a money parody cap event for absurd wealth.
  * When net wealth passes the runaway cap, the event confiscates excess money.
  * The player is left with **£1,000,000,000**.
  * The event wipes:
    * Cash.
    * Savings.
    * Fixed-term deposits.
    * HBSC notices.
    * Bailey rent deposit.
  * Loan debt is kept.
  * The event returns the player to their current or latest valid location instead of forcing an orphanage teleport.
  * The event avoids firing during:
    * Combat.
    * Active events.
    * Active bad ends.
* Rebalanced income and costs.
  * Avery payouts now scale with model fame as well as love and endearment.
  * Gentleman’s Club blackmail rewards have been increased.
  * Horse racing betting no longer has the **£10,000** weekly cap.
  * Horse racing no longer has the **£10,000** preset bet.
  * Horse racing can now randomly injure the backed horse.
  * Too many injured horses closes betting until the weekly reset.
  * Losing horse bets now adds stress.
  * Repeated same-day losses can escalate to trauma.
  * MMA gym lesson costs have been reduced:
    * Footwork: **£22**.
    * Striking: **£28**.
    * Kicking: **£28**.
    * Conditioning: **£50**.
* Updated shop lock difficulty and paid trespass purchases.
  * Increased lock difficulty and penalties for:
    * Bike depot.
    * Cosmetics shop.
    * Jewellery shop.
  * Added paid break-in purchase options.
    * These add trespass crime.
    * These also add kindness fame.
  * Preserved the original theft routes.
  * Fixed jewellery and boutique theft handling.
* Tweaked the police side door.
  * The skulduggery police side-door chance is now decided once per day.
  * It is no longer re-rolled every time the player enters Barb Street.
  * If the player has enough skulduggery and discovers the door, it stays available for the rest of the day.
  * If the player fails to find it, it stays unavailable until the next day.
  * This prevents the side-door from randomly vanishing between visits while keeping the daily chance behavior intact.
  * The permanent police access card route is unchanged.

## Rebalancing and Fixes:
* Fixed Poppy appearing already pregnant on a new game.
  * Poppy could appear pregnant with no due date immediately after starting a new game.
  * This was caused by faulty data setup that flagged her as pregnant by default.
  * Poppy now starts correctly as unpregnant.
* Fixed a missing pronoun in Poppy’s text.
* Fixed missing pronouns in Harper’s text.
* Fixed the **X-Change blackmail quest**.
  * Stall sales now track profit correctly.
    * This fixes the “Corrupted variables” error on Stall Sell.
    * This also fixes the missing fame bonus.
  * The air-hockey quest pill no longer triggers an unintended spike.
  * Quest progress trackers are now pre-initialised to prevent similar issues.
* Fixed the **Water Dragon tail**.
  * The short blue tail image existed but had no mirror entry, so it could not be selected.
  * The short Water Dragon tail now uses the purple angel-chimera tail to match the long purple variant.
* Fixed the **Dumb Bitch** feat and setting toggle.
  * The “Dumb Bitch” feat now unlocks once the PC’s brain is fully fried.
    * Grades, skulduggery, and willpower must all be bottomed out.
  * The feat is no longer gated behind a near-impossible extra requirement.
  * Fixed the Dumb Bitch checkbox in X-Change settings.
    * The checkbox could show the wrong on/off state.
    * The shown state could fail to match the actual effect.
  * The toggle now reliably reflects and controls whether the effect is active.
  * Existing saves are auto-migrated to the corrected setting.
* Fixed a birth crash caused by X-Changed bodies.
  * Getting changed from female to male while pregnant no longer breaks the game when the PC’s water breaks.
  * Giving birth in the asylum or prison, or getting treatment from Harper, could previously throw a “no usable links” error.
  * This happened because the game lost track of what the PC was carrying once their vagina was gone.
  * The asylum, prison, and forest shop birth scenes now have the same safety net as hospital birth.
  * Unexpected pregnancy types should no longer dead-end a birth scene.
* Fixed the **Anti-fertility Pill**.
  * The Anti-fertility Pill previously removed the basic fertile effect but left Hyper Fertility active.
  * Taking another pill did nothing.
  * It now correctly cancels Hyper Fertility, including faster pregnancy and multiples.
  * It still leaves normal fertility untouched, matching the item description.
  * The Anti-fertile Pill should still be used if the player also wants to remove fertility.
* Fixed the **X-Change settings page** crashing on corrupted saves.
  * Some saves carried invalid values for X-Change pill sliders, including:
    * 0.
    * NaN.
    * Missing values.
  * Affected sliders included:
    * Spike rates.
    * Combat-pilling chances.
    * CumCure time.
    * Resistance penalty.
  * Opening X-Change Settings could crash with errors like “default value (0) is less than min value (1)”.
  * Loaded saves now auto-repair these values back into their valid range.
  * Affected players only need to load their save and take one step.
  * No new game is required.
* Fixed a broken DoLP setting.
  * Saves where `parasiteCapMult` somehow became 0 are now repaired.
* Fixed the Bakunawa tail.
  * The Bakunawa tail can now flaunt and cover correctly.
* Fixed X-Change removing natural innocence.
  * Natural innocence now survives temporary X-Change innocence effects when the player returns to their original body.
  * This applies as long as awareness has not actually been lost.
  * Pill-granted innocence still ends normally.
  * Depleted innocence still converts back to trauma.
  * Old active saves are repaired safely.
* Fixed the penis setting slider.
  * The penis slider did not show when choosing penis genitals during character creation.
  * It only appeared after clicking another tab and returning.
  * The slider now displays correctly.
* Fixed the sports bra main image.
  * The sports bra was incorrectly marked as having no main image layer.
  * This caused only breast-size variation images to load.
  * The normal full, frayed, torn, and tattered clothing images now display again.
* Fixed clothing transparency.
  * Added missing `overupper` and `underlower` handling.
  * Fixed transparency issues on several clothing items.
* Fixed pregnancy settings and the cheat menu.
* Fixed broken vanilla backwards compatibility.
* Fixed curious attire feats not unlocking on old saves.
* Continued lag reduction and code cleanup.
  * Cleaned up more code.
  * Tidied some narration.
  * Fixed doubled sentences in the Mason pond.
  * Reduced wall-of-text issues in Sydney library.
  * Improved bad mobile UI in loft cooking for the orphanage.
